# Design System

## Status

Not started. This file is a Stage 0 placeholder for the later Google Stitch design process and approved design-system specification.

## Approved Direction From Master Build Spec

The future visual style should be:

- Professional.
- Protective.
- Practical.
- Modern.
- Trustworthy.
- Mobile-first.
- Easy to read in a truck cab, break room, or on a phone.
- Distinct from a government website.
- Distinct from an insurance company.
- Calm rather than fear-driven.

Future design exploration should use:

- Dark navy.
- Slate.
- White.
- A restrained safety-orange accent.
- Large readable typography.
- Strong contrast.
- Generous spacing.
- Clear cards.
- Simple icons.
- Moderately rounded elements.
- Clear primary and secondary buttons.

Future design exploration should avoid:

- Police lights.
- Handcuffs.
- Crashes.
- Frightened workers.
- Drug imagery.
- Government seals.
- Fake badges.
- Overused shield graphics.
- Dense dashboards.
- Corporate stock-photo clichés.
