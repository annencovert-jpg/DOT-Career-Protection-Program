# Source Directory

This directory is reserved for the future website source code.

## Stage 0 Status

No website framework has been initialized during Stage 0.

Do not add React, Vite, TypeScript, Tailwind, Firebase, Cloudflare, HubSpot, payment integrations, or other production integrations until the appropriate later stage is authorized.

## Future Intended Structure

The master build spec recommends a future structure similar to:

- `src/components`
- `src/pages`
- `src/layouts`
- `src/content`
- `src/content/resources`
- `src/config`
- `src/styles`
- `src/lib`

These directories have not been created in Stage 0 because the website build has not started.
