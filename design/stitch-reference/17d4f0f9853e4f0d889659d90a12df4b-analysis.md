## 1. File Classification

## 11. Visual Styling Tokens (Colors, Fonts, Spacing, Cards, Buttons, and Responsiveness)

The HTML specifies its visual tokens inside a custom Tailwind config block and implements them using utility classes:

### Colors (Tailwind theme extend)
* **Primary (Text / Interactive):** `#000000` (Main), `#131B2E` (Primary Container / Dark Navy)
* **Secondary (Slate/Muted):** `#515F74`
* **Accent (Orange):** `#FB923C` (`safety-orange-muted`)
* **Backgrounds:** `#f7f9fb` (`bg-surface`/`background`), `#ECEEF0` (`surface-container`), `#F2F4F6` (`surface-container-low`), `#FFFFFF` (`surface-container-lowest` / White)
* **Borders & Outlines:** `#E2E8F0` (`border-subtle`), `#76777d` (`outline`), `#c6c6cd` (`outline-variant`)
* **Error States:** `#ba1a1a` (`error`), `#ffdad6` (`error-container`)

### Fonts & Typography
* **Font Families:**
  * `body-md`, `body-lg`, `display`, `headline-md`, `headline-lg`, `headline-lg-mobile` &rarr; **Hanken Grotesk**
  * `label-caps`, `button` &rarr; **Inter**
* **Font Sizes & Settings:**
  * `display`: `48px`, Line Height `56px`, Letter Spacing `-0.02em`, Font Weight `800`
  * `headline-lg`: `32px`, Line Height `40px`, Font Weight `700`
  * `headline-lg-mobile`: `28px`, Line Height `36px`, Font Weight `700`
  * `headline-md`: `24px`, Line Height `32px`, Font Weight `600`
  * `body-lg`: `20px`, Line Height `30px`, Font Weight `400`
  * `body-md`: `16px`, Line Height `24px`, Font Weight `400`
  * `button`: `16px`, Line Height `20px`, Font Weight `600`
  * `label-caps`: `12px`, Line Height `16px`, Letter Spacing `0.05em`, Font Weight `700`

### Spacing & Shape (8px Base Grid)
* **Spacing Variables:**
  * `gutter`: `1.5rem` (24px)
  * `margin-mobile`: `1rem` (16px)
  * `margin-desktop`: `2.5rem` (40px)
  * `stack-sm`: `0.5rem` (8px)
  * `stack-md`: `1.5rem` (24px)
  * `stack-lg`: `3rem` (48px)
  * `container-max`: `1280px`
* **Border Radius (Shapes):**
  * Default: `0.25rem` (4px)
  * Large (`lg`): `0.5rem` (8px)
  * Extra Large (`xl`/`rounded-xl`): `0.75rem` (12px) (The moderate standard for layout cards)
  * Full (`full`): `9999px`

### Component Styles
* **Card Styles:** Moderate standard corner radius (`rounded-xl` / 12px), background white, subtle light border (`border-border-subtle` / `#E2E8F0`), hover state shadows (`hover:shadow-md transition-shadow`).
* **Button Styles:**
  * **Primary:** `bg-primary` (Black), `text-on-primary` (White), 8px border radius (`rounded-lg`), bold font (`font-button text-button`), active scale click micro-interaction (`active:scale-95`).
  * **Secondary:** Bordered style, border Slate `#515F74`, Slate text, hover transition with bg change.
  * **Critical:** Safety Orange background (`bg-safety-orange-muted`), Black/Navy text.
* **Alert / Notice Styles:** Yellow-Orange left-accent border (`border-l-4 border-safety-orange-muted`), white background card with rounded-right corners, light shadow, and an informative leading icon.

### Responsive Rules
* **Layout Max-Width:** Confined to `max-w-1280px` centered on large viewports.
* **Padding Margin Adjustments:** Padding scales dynamically based on screens: mobile margins are `px-4` (`px-margin-mobile`), desktop margins are `md:px-10` (`px-margin-desktop`).
* **Grid Layouts:** CSS grid layouts shift based on breakpoint tags, e.g. benefit cards are `grid-cols-1 md:grid-cols-3` or resources are `grid-cols-1 md:grid-cols-2 lg:grid-cols-3`.
* **Sticky Mobile Navigation:** The top navbar navigation menu hidden on mobile (`hidden md:flex`), replaced by a mobile sticky bottom navigation bar (`fixed bottom-0 lg:hidden flex`).

## 12. Direct References Usable for the React Website

The following elements can be ported directly into the public React/Vite/TypeScript website located in `website/`:

1. **Tailwind Configurations:** The extended color hexes (specifically Dark Navy `#131B2E`, Slate `#515F74`, and Safety Orange `#FB923C`), exact custom typography mappings, and the custom spacing scale can be injected directly into the Tailwind configurations or root stylesheet.
2. **Typography Font Weights & Line Heights:** The specific pairings of *Hanken Grotesk* for headlines/display and *Inter* for interactive elements (labels/buttons) ensure consistent professional styling.
3. **Visual Mock Content & Exact Copy:** All exact text, including benefit card descriptions, pricing packages ($7.99/mo and $80/yr), FAQ questions/answers, the three protection path steps, and footer navigation structure, provide a pre-approved baseline for content population.
4. **Imagery Ethos & Metadata:** The pre-defined `data-alt` attributes on image elements (such as clean commercial truck drivers, serene workstations, and peaceful highway scenery) represent the desired brand positioning (avoiding distress and chaos). These descriptions can be used to select exact stock photography and write descriptive alt text for accessibility.
5. **Layouts and Components:** The markup structures for the cards, bottom navigation models, and micro-interactions (using `active:scale-95` on button clicks) are highly modular and can be directly translated to Tailwind-styled React components.
