# DOT Career Protection Program Website

This repository contains the planning foundation for the future public website for the **DOT Career Protection Program**.

## Project Purpose

The planned website will support a membership program for CDL drivers, FMCSA-covered workers, and other DOT safety-sensitive workers. The primary goal, when the website is built in a later stage, will be to explain the membership clearly and support monthly or annual enrollment.

The membership concept approved in the master build spec includes preventive DOT drug-and-alcohol education, regular educational emails, defined benefits if an eligible member later experiences a DOT drug or alcohol violation, and general member support and next-step navigation.

## Planned Domain

The planned public domain is:

- `49CFR40.com`
- `49cfr40.com`

The public brand is **DOT Career Protection Program**. The domain supports the brand and should not be treated as the product name.

No live domain, DNS, hosting, payment, HubSpot, or production integration has been connected in Stage 0.

## Current Stage

This repository is currently in **Stage 0: repository foundation**.

Stage 0 includes documentation scaffolding only. It does not include the website build.

During Stage 0, this repository must not initialize or add React, Vite, TypeScript, Tailwind, Firebase, Cloudflare, HubSpot, payment providers, hosting configuration, DNS changes, production-domain connections, secrets, or credentials.
